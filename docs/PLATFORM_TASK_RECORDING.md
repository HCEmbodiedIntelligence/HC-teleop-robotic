# 平台连接、任务录制与自动上传

平台接入依据平台仓库的 `docs/robot-ingest-onboarding-proposal.md` 和 `docs/robot-task-recording-proposal.md`：10 分钟链接、同组织有效任务、不增加任务指派、新连接默认自动上传。录制入口按用户要求保持直接可用：未选择任务时默认本地录制，任务设置自动保存并由网页与手柄共用。

## 部署

1. 平台先部署包含本次代码的后端，并按现有迁移流程执行 `python -m hc_data_platform.core.migrations upgrade-expand`。新增 `ingest/022_robot_connections.sql` 只增加连接票据与本地配置映射表，已有身份、凭据和归属不变。前端同步部署生成后的构建产物。
2. 机器人执行现有 `./install.sh` 安装更新后的依赖与上传客户端，然后使用原启动方式重启服务。录制和上传状态保存在原 `uploads.queue_directory`；未配置时默认相对配置目录的 `../runtime/upload_queue`。不要移动或删除此目录，也不要将它设在录制目录内。
3. 机器人实际配置来自正在使用的 `HC_ROBOT_NAME` / `robot_profiles.active` 和对应 profile、控制器 model、URDF；不需要操作员输入设备 ID、Token 或凭据路径。平台设备须启用并绑定已发布、资产可用的模型。配置或既有映射冲突时须修复配置。

## 操作

1. 平台打开“数据源 → 机器人接入”。新设备用“接入机器人”，已有设备用“查看接入详情”，点击“复制连接链接”。没有新增独立机器人接入页面。
2. 机器人页面进入“上传管理 → 平台连接与上传设置 → 连接设置”，粘贴完整连接链接，点击“连接”。服务兑换并保存凭据，页面自动取得任务。连接成功会显示机器人、平台和自动上传开关。
3. 平台创建进行中的任务并配置好数据集和区域。机器人在“上传管理”按任务名称选择，可搜索名称/编号、按项目筛选、分页或刷新。随后到“话题录制”选择话题并开始录制。页面可见时每 30 秒刷新任务，作业进度每 5 秒刷新。
4. 开始录制时提交所选任务，服务在同一临界区验证并保存本段平台、机器人、任务、归属和自动上传设置。录制时显示固定任务；切换浏览器窗口、后续选择及服务重启不会修改已记录的归属。
5. 停止录制后后台整理、校验封存和入队。上传、平台处理和质检分别显示。MCAP/both 模式上传原 MCAP；lerobot 模式上传转换完成的数据集。后台转换不阻止下一段录制。
6. 左手柄 X 开始录制、Y 结束录制，不需要额外启用或保存手柄设置。“上传管理”的任务选择自动保存，网页与手柄共用，服务重启后保留；未选择任务时默认录到本机，不需要先打开网页。已选择平台任务时，两个入口调用同一验证/快照逻辑，强制忽略话题频率不会跳过任务检查。设置保存失败时页面明确提示，继续使用原设置，不会悄悄改投其他任务。
7. 所有录制都先保存到本机。“暂不关联平台任务”（原“仅本地录制”）表示本段不绑定任务、不自动上传，适合断网或暂未确定任务时使用；关联任务但关闭自动上传也会保存在本机。录制中断网不影响正在写入的数据；若已选平台任务，断网后开始新段须切换为暂不关联任务。恢复网络后，在该条记录点击“选择任务后上传”，不使用页面当前任务自动补绑。

## 恢复与兼容

- 首次兑换须在 10 分钟内完成。为恢复响应丢失，仅完全相同的随机连接请求 ID 和本地配置可在首次兑换后 24 小时内重取同一凭据；不能生成第二个凭据。普通连接不撤销其他凭据，管理员撤销后的凭据不能被重试复活。
- 连接票据明文不写磁盘；服务只保存票据摘要与重试 ID。长期凭据单独存为 0600 文件；浏览器不持久保存，录制、封存、清单和日志不包含凭据。同平台/组织/身份的新连接更新同一个服务托管凭据引用，历史作业可以重试而不改任务。
- 旧连接保留原自动上传开关、有效凭据引用与队列。旧队列出现在上传列表，可直接重试。旧 `env:` 或外部文件凭据引用不自动改写；若这类凭据被管理员撤销，仍需维护其原引用。
- 任务关闭、取消、删除、跨组织或归属变化阻止新录制/新上传，源数据保留。已创建的上传会话按原身份和清单对账；不会把录制重投另一个任务。
- 录制未完整关闭时标为中断并保留源文件，不自动上传。完整停止后在整理、封存、入队任一步重启可恢复。历史 MCAP 必须能确认 profile 和采集时间；历史 LeRobot 还须保留对应源 MCAP。缺少证据的历史数据不自动推断归属。
- 已有封存或上传记录不可通过补选任务覆盖。被队列引用的本地文件禁止从普通录制列表删除，需在独立维护流程处理。
- 已同步到 main 的 5d23f05 上传集成；当前 main 没有自动分段会话入口；已覆盖现有 HTTP 和手柄入口。旧连续采集包队列保留并继续按原会话快照上传，没有移植 humanoid 的整套自动分段管理器。
